# Java 从入门到精通学习站

这是一个以尚硅谷 Java JDK 17 课件为主线整理的个人学习网站，将章节正文、电子教材、学习路线图、示例代码和配套资料集中到一个便于检索与阅读的静态站点中。

## 在线访问

- 自定义域名：https://github.qinyu.online/
- GitHub Pages：https://qinyugithub.github.io/
- 资料仓库：https://github.com/qinyugithub/qinyugithub.github.io

## 内容概览

- 18 个完整章节，覆盖 Java 基础语法、面向对象和高级应用
- 711 个可全文搜索的知识小节
- 2,402 份原始学习资料，总计约 502.5 MB
- 包含 Markdown 课件、PDF、PPTX、XMind、Java 源码、图片及工具资料

## 网站功能

- 以课件章节为主菜单，按照学习阶段组织内容
- 支持章节标题和课件正文全文搜索
- 支持学习进度记录与当前位置收藏
- 提供浅色、深色主题
- 响应式布局，可在电脑和手机上阅读
- 资料库支持按章节、文件类型和关键词筛选

## 目录说明

- `index.html`：网站首页与课程地图
- `chapter.html`：章节阅读页面
- `resources.html`：完整资料库
- `data/`：章节索引、搜索索引及资源清单
- `m/`：电子教材、课件、源码及全部配套资料
- `styles.css`：网站样式
- `app.js`：搜索、进度、收藏及页面交互

## 本地预览

克隆仓库后，在仓库根目录启动任意静态文件服务器，例如：

    python -m http.server 8000

然后访问 `http://localhost:8000/`。

> 不建议直接双击 HTML 文件打开，因为浏览器可能会限制本地 JSON 数据的读取。
